# BeanBuddy Solo — Rechtstexte

Datenschutzerklärung und Nutzungsbedingungen der App **BeanBuddy Solo**,
öffentlich erreichbar, weil beide App-Stores das verlangen.

**Diese Seite wird nicht von Hand gepflegt.** Sie wird aus dem Quelltext der
App erzeugt:

```
npm run legal:html      # im App-Repo
```

Das Ergebnis (`docs/rechtstexte.html`) wird hier als `index.html` abgelegt. So
kann die Web-Fassung nicht von der Fassung in der App abweichen — und genau
das war der Grund, den früheren Weg über ein Google-Dokument aufzugeben.

Der Quelltext der App liegt in einem privaten Repo; hier steht ausschließlich
die veröffentlichungspflichtige Seite.
